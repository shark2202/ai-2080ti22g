### 缺陷一：题库答案位置严重偏斜（分数虚高的根因）
- 现象：中文知识 28/40 答案是 B、英文 26/40 是 B、逻辑 13/20 是 B
- **负对照**：闭眼恒答 B 可得 70% / 65% / 65% —— 三个维度失去区分度
- 修复：新增 `scripts/balance_answer_positions.py`，按题号排序后**严格轮转**分配 A,B,C,D
  - 先试了随机分配，极差只从 61 降到 14（中文 C位仍偏少）→ 改为轮转后极差归零
  - 结果：40题→10/10/10/10，20题→5/5/5/5；恒答最优字母基线 70%→25%
- **闸门**：`validate.py` 新增分布检查，极差 > 15% 即判不合格并提示跑修复脚本
  - 已用正反两例验证（注入全 B → exit 1 + 明确报错）

### 缺陷二：--run-id 会复用非空目录，混入上一轮数据
- 现象：重跑 `--run-id after_balance` 时旧记录被当"已完成"跳过，报告混入历史数据
- 修复：非 `--resume` 时若目标目录已存在且非空 → 直接报错，要求换 id 或用 --resume
- 已验证：重复 id 被拒绝，自检通过
